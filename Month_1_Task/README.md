# 🎲 Task 1 — Dice Rolling Game

The **Dice Rolling Game** is a Python command-line application that simulates rolling two six-sided dice.

### ✨ Features

* 🎲 Roll two six-sided dice
* 🔢 Calculate the total score
* 🔥 Detect doubles
* ⭐ Detect Lucky 7
* 🏆 Detect the highest possible score
* 📜 View complete roll history
* 📊 View game statistics
* 📈 Calculate average score
* ❌ Handle invalid menu choices
* 🚪 Exit with a game summary

### 🧠 Concepts Practiced

* `random` module
* `random.randint()`
* Functions
* Lists
* Tuples
* `while` loops
* Conditional statements
* `max()`, `min()`, and `sum()`
* User input/output
* f-strings

### ▶️ Run the Game

Open a terminal inside the `Task_1` directory and run:

```bash
python Dice_Rolling_Game.py
```

* 📋 View all tasks
* ✅ Mark tasks as completed
* 🗑️ Remove completed tasks
* 📊 View task summary

* 🔢 Track completed and pending tasks
* ❌ Validate empty task names

### 🧠 Concepts Practiced
