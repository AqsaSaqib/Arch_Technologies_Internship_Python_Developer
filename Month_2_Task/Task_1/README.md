# 🎯 Number Guessing Game
A simple and interactive **Number Guessing Game** developed in Python as part of my **Python Developer Internship at Arch Technologies**.
The game allows the player to choose a difficulty level, guess a randomly generated number, receive hints, and earn points based on their performance.

## ✨ Features
* 👤 Player name input
* 🎮 Three difficulty levels
* 🔢 Random number generation
* ❤️ Limited attempts
* ⬆️ Higher and lower hints
* 🔥 Close-number hints
* ⭐ Score system
* 🔄 Multiple rounds
* 🛡️ Input validation
* 📊 Final score and game summary

## 🛠️ Technologies Used
* Python 3
* `random` module

## 🎮 Difficulty Levels
| Difficulty | Number Range | Attempts |
| ---------- | -----------: | -------: |
| Easy       |       1 - 50 |        8 |
| Medium     |      1 - 100 |        7 |
| Hard       |      1 - 200 |        6 |

## ▶️ How to Run
1. Make sure Python 3 is installed.
2. Save the code as:
```text
Number_guessing_Game.py
```

3. Run the program:
```bash
python Number_guessing_Game.py
```

## 🧩 How It Works
1. The player enters their name.
2. A difficulty level is selected.
3. The program generates a random number.
4. The player tries to guess the number within the available attempts.
5. The program gives **Too High** or **Too Low** hints.
6. If the player guesses correctly, a score is awarded.
7. The player can play multiple rounds.
8. At the end, the total score and rounds won are displayed.
